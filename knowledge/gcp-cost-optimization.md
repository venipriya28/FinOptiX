# Google Cloud Well-Architected: resource usage

## Source
Google Cloud Well-Architected Framework, Cost optimization: https://docs.cloud.google.com/architecture/framework/cost-optimization/optimize-resource-usage

## Retrieved guidance
Google Cloud guidance emphasizes understanding workload requirements and consumption patterns, then provisioning resources to match those needs. Resource optimization should be coordinated with workload requirements and project architecture.

## FinOptiX interpretation
FinOptiX presents recommendations for human review and models workload peaks from historical observations. Its simulation does not validate application-specific service-level objectives.
