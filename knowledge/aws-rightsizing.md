# AWS Well-Architected: rightsizing and idle resources

## Source
AWS Well-Architected Framework, COST06-BP03: https://docs.aws.amazon.com/wellarchitected/2023-10-03/framework/cost_type_size_number_resources_metrics.html

## Retrieved guidance
AWS guidance recommends selecting resource type, size, and count from workload metrics. Review compute performance data, identify idle and underutilized instances, and use rightsizing recommendations as inputs to workload decisions. A recommendation must still be checked against workload performance needs and operating context.

## FinOptiX interpretation
FinOptiX uses observed utilization and resource catalog capacity for a proposed resize. Its local catalog prices are illustrative and do not reproduce AWS billing or Compute Optimizer recommendations.
